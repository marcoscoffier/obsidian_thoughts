# Mandelbrot Set Pixels, Notation & Typography

the pixels in a diagram of Mandelbrot's set pose an interesting problem to a notational system. Each pixel is assigned a color by a point in its area or an average of that area—but if that pixel is broken into more which happens when you zoom into the set it becomes many different colored pixels. It can become any of the colors used in the representation of the set. The colors, however, always mean the same thing I believe goes to ∞ after *x* number of terms where there are different colors for different values of *x* (1–100, 100–1000, etc.). The denotata change w/ each zoom?

- "typography is mechanized or computerized calligraphy" - p. 359 *Word & Image* 1993.
- can character be defined apart from its mark?
